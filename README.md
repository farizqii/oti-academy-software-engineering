# Personal Productivity Dashboard

## Deskripsi

Aplikasi web untuk membantu user mencatat Notes dan
mengelola aktivitas produktivitas secara personal.

## Problem

Catatan dan aktivitas produktivitas sering tersebar di
beberapa tempat sehingga sulit dipantau.

## Target User

Siswa atau individu yang ingin mengelola catatan dan
aktivitas produktivitas dalam satu dashboard.

## Fitur

- Authentication.
- Protected Dashboard.
- CRUD Notes.
- User-owned Notes.
- Validation.
- Loading state.
- Empty state.
- Error handling.
- Fitur tambahan: To-do List.

## Tech Stack

- Next.js.
- React.
- TypeScript.
- Tailwind CSS.
- Clerk.
- Prisma ORM.
- PostgreSQL.
- Supabase.
- Vercel.

## Local Setup

1. Clone repository.
2. Jalankan npm install.
3. Buat file .env.
4. Isi environment variables.
5. Jalankan npx prisma generate.
6. Jalankan npm run dev.

## Environment Variables

DATABASE_URL
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY
CLERK_SECRET_KEY
